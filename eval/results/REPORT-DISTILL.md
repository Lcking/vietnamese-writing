
# 蒸馏实验报告(A/B)

## 设计
- 模型:本地 qwen-3.8-27b-awq(打分与生成都用它)
- 三层管线:启发式全量粗筛(253万→2万)→ 模型精评(随机抽1010条,4维rubric打分)→ 择优240条
- A/B:同模型同评测集同配置(仅体裁规则,无全局),只换 few-shot 范文池
  - A组:现有启发式精选池(208条)
  - B组:蒸馏top池(240条,q_score 8.25-9.25)

## 自动指标

| 成功率 | 8/8 | 8/8 |

| F组通过 | 2/3 | 2/3 |

## 人工评述(非母语AI评,仅供定位,非结论)
- A2:A组编"宣布公布名字"情节较轻;B组编"Chiều 25/6"具体日期+紧急会议,更重
- B1:两组都补了题目外信息(赛事框架/教练名/球员停赛),B组细节更丰富但同样未证实
- C1/C2:B组短帖更自然("có vé"、更利落)
- F2:两组都把"离场/伤情"两个独立事实拼成因果——都违规(检测器抓到)

## 结论:蒸馏池 = 质量持平略优,非质变
1. **小样本下(8案例)差异在噪声范围内**,不能声称"蒸馏显著提升质量"
2. B组在"风格类"任务(短帖)上观感略好;在"事实纪律"上两组都会虚构——
   **根因在模型本身而非范文池**:范文教的是"怎么写",拦不住模型编"写了什么"
3. 真正防虚构的是:事实分层提示(已加)+ 检测器(已加)+ 母语人审(未做)
4. 蒸馏的真实收益是**可解释性与可维护性**:240条都有 q_score,以后扩池、
   换领域、按体裁配额都可用同一条管线,而不是黑盒启发式

## 建议
- 范文池换不换:可选。B组略好且管线可复用,建议**换成蒸馏池**并保留旧池
- 防虚构:继续用 lite profile + check_fabrication,别指望范文池解决
- 母语盲评仍是唯一能验证"地道度"的路径
