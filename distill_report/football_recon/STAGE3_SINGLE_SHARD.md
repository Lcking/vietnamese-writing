## 0. 三处修正的复现与验收

### 问题一：只存前 300 字符 → 两张表算不出

**复现**（v1.6.8）：记录只有 `head: raw[:300]`，脚本内无任何 ngram/entity 统计代码。

**修**：全文落盘 `distill_work/football_full/<分片>.jsonl`（**不进仓库**），
字段 `id / tags / year / text`；确认表仍只展示前 300 字符。

**验收**：单分片产出全文文件，`--merge` 成功生成两张表。

### 问题二：赛果规则过宽

**复现**（v1.6.8）：办公室省电文判为**是**；`giải/đội/hiệp` 命中
`giải pháp/đội ngũ/hiệp hội`。

**修**：
- 语境词表删掉普通词，只保留比赛专属词（trận đấu/ghi bàn/bàn thắng/
  thủ môn/trọng tài/thẻ vàng/thẻ đỏ/HLV/vòng N/V.League/luân lưu/
  sân vận động…），并要求命中 **≥2 个不同的词**
- 新增排除词：bóng chuyền/bóng rổ/quần vợt/cầu lông/bóng bàn/pencak/
  quyền anh/**futsal**（暂不收录）
- 比分改为 wash-then-match：先挖日期（07-25 / 12/07/2025）与量词
  （1-2 thìa / 5-10 kg），再匹配
- **语境词必须落在比分 ±400 字符窗口内**（修聚合页误判）

**验收**（单测 4 段）：
| 文本 | 结果 | 期望 |
|---|---|---|
| 办公室省电 | 否 | 否 ✓ |
| 女排 3-1 | 否 | 否 ✓ |
| 五人制 2-1 | 否 | 否 ✓ |
| 真 V.League 赛果 | 是 | 是 ✓ |

量级变化：电子书分片赛果 30 → **1**；20 万行新闻 998 → **954**。

### 问题三：去重会漏掉近似重复

**修**：改标准分段 LSH（128 哈希 / 32 段 × 4 行），任一段完全相同即同桶。

**验收**（单测，真实相似度 ≥0.8 的稿件对）：
| 改动比例 | 判重率 | 要求 |
|---|---|---|
| 1% 的词 | ≥90% | ≥90% ✓ |
| 2% 的词 | ≥90% | ≥90% ✓ |
| 4% 的词 | ≥90% | ≥90% ✓ |

## 4. 已知的规则上限（如实说明）

规则粗判无法达到 100% 精确。抽查中出现的可疑类型：
- 主帅/训练/伤病新闻（有比分引用但主体不是赛果）
- 博彩站广告（含 soi kèo + 比分）
- 赛前言论（引用了往绩比分）
这些需要人工确认环节裁定，或后续加更强的赛果特征（如要求首段含
"kết thúc/đánh bại/hạ" 等结果动词）。
