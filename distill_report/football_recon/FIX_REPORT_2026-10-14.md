## 1. 三处修正

### ① 比分清洗（UNIT_RE）—— 标准写法漏判

原 `UNIT_RE` 里 `tr`、`giờ`、`phút` **没有词边界**：
- `tr` 吃掉 `trước` / `trên` / `trong` → 最常见的赛果写法全部漏判
- `giờ` / `phút` 被当量词 → `1-0 giờ nghỉ`、`1-0 phút 90` 漏判

改法：
- 每个单位加词边界；`tỷ` 用 `(?!\s*số)` 避免吃掉「tỷ số」
- **删掉 `phút` 和 `giờ`**
- 补 `tấn / gam / ml / l / km / inch / foot` 等真量词

### ② 博彩稿隔离

原 `classify()` 只给博彩稿**多加**一个标签，它仍同时进 `ket_qua`。

改法：命中博彩词 → **只返回 `["betting"]`**，不进任何其他类别，
也不参与词组表 / 名称表统计。词表扩充：`cá cược / đặt cược / kèo nhà cái /
link vào / W88 / Fun88 / 188bet / nhacai / keonhacai / m88 / 12bet / bk8 / sbobet`。

### ③ 结果动词改为排序分（不做硬过滤）

新增 `ket_qua_score(t)`：首段/标题有比分 +3、首段有结果动词
（thắng/đánh bại/hạ/hòa/thua/kết thúc）+2、全文 ≥2 个进球分钟 +2（1 个 +1）。
挑选候选范文 / 抽查样本时**按分数从高到低**，不再硬过滤掉真赛果。
