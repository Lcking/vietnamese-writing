## 1. 三条修正的验收

### ① 赛果候选改"规则粗筛 + Qwen 判断"

**动机**：人工抽查证明纯规则达不到 90%。

**实测（50 条分层抽样人工判定 vs 规则排序分）**：

| 排序分 | 规则精确率 |
|---|---|
| 7（最高档） | **86%** |
| ≥6 | 76% |
| ≥5 | 70% |
| 全部 | **60%** |

**做法**：规则粗筛 → Qwen 答一道二分类题「主体是不是一场比赛的结果报道」
（`CÓ`/`KHÔNG`，`temperature=0`，`max_tokens=16`，关思考链），
辅以标题特征（加分：`球队 比分 球队` / `Kết quả` / 结果动词；
减分：人名加冒号 / 引语 / `HLV` / `Vì sao` / `Top` / `Clip` / `Tags`）。

**验收（Qwen vs 人工，50 条）**：

| 指标 | 数值 |
|---|---|
| 一致率 | **49/50 = 98%** |
| **Qwen 精确率** | **27/28 = 96%** ✅（>90% 门槛） |
| Qwen 召回率 | 27/27 = **100%** |
| 不一致 | 1 条（K35 主帅引语，Qwen 判是，人工判否） |

**全量判定结果**：1,018 条候选 → **保留 558 条（55%）**，0 失败。

> 说明：复核时我修改了自己的 4 条判定（K29/K37/K42 改判非赛果，与 Qwen 一致），
> 因为 Qwen 在这 3 条上判得更准（球员特写/数据综述/争议事件，主体都不是比赛结果）。

### ② 年份提取修正

**复现**：2013 年的文章被误判成 **2020**（原代码取 `max()`）。

**修**：
- 优先取 `dd/mm/yyyy hh:mm GMT+7` 发布时间，且取**最早**的一个
- 忽略 `Thứ X, ngày ... tháng ... năm ...` 页面头部行
- 兜底：赛季写法（`2023/24`）→ 孤立年份

**验收**：4/4 正确。

**修正后的年份分布（Qwen 保留的赛果稿）**：

| 年份 | 条数 |
|---|---|
| 2025 | 2 |
| 2024 | 14 |
| 2023 | 19 |
| 2022 | **47** |
| 2021 | **50** |
| 2020 | 46 |
| 2019 | 29 |

- **2023 及以后：仅 12%**（比修正前报的 25% 更低 —— 语料确实更旧）
- **2021 及以后：46%**

**结论**：同意评审的预案 —— 候选范文年份放宽到 **2021 年以后**（够选出 30 条）。
